# Organization Onboarding

In this feature, implement the organization onboarding.

- Check the user email domain, if the domain already exist then the new signup user should be automatically blong to that organization.
- The idea is: When user signup for the first time, the dashboard layout should be the same but there should be a form to fill their organization details.
- After the organization created, then redirect the user to the dashboard.
- The user should be able to enter (Organization name, Address and Industry Type).
- A default branch ("Main") should be created automatically.
- A Unique slug should be generated for the organization.
- The Industry type should be a dropdown list that user can select from.
- Admin selects 2–15 professions the org offers, from the Bundesagentur für Arbeit "Berufe A–Z" catalog.
- Look through context/architecture.md for naming and convintion.
- Try to implement the code clean and standard.
